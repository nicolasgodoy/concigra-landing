Cómo funciona

De múltiples registros a una operación conciliada

01

Creá la operación

Definí campo, lote, labor, superficie, contratista y precio acordado.

02

Incorporá la información

Desde contratistas, maquinaria, GPS, telemetría, sistemas de gestión y otras fuentes.

03

Compará

Concigra relaciona los registros de una misma operación.

04

Detectá diferencias

Cuando las fuentes no coinciden, Concigra identifica la discrepancia.

05

Resolvé

Las partes aportan información y evidencia para explicar la diferencia.

06

Conciliá

La operación queda registrada con su resultado conciliado.

07

Liquidá

El resultado conciliado puede utilizarse como base para determinar la superficie y el importe correspondiente.

Confianza

Una plataforma independiente

Concigra funciona como una capa independiente para relacionar las diferentes fuentes de información.

Concigra no representa a:

el productor
el contratista
el fabricante de maquinaria
un sistema de gestión específico

El objetivo no es decidir quién tiene razón.

El objetivo es facilitar que las partes puedan determinar qué ocurrió y dejarlo registrado.
